# Rules folder

How to work on this project. One topic per file.

| File | Read it when |
|---|---|
| git-and-commits.md | Before any commit, branch check or git command |
| tdd-and-testing.md | Before writing or running any test |
| code-design.md | Before writing any service, controller or model |
| reply-style.md | Before writing any reply, report or user-facing text |
| report-format.md | When ending a task with a report |
| ui-and-frontend.md | Before any page or component work |
| security.md | Before anything touching login, phones, PINs, data or permissions |
| session-hygiene.md | At the end of every task, to decide whether to suggest a new session (then see ../handoff/) |
| chat-sessions.md | Only in a chat session, not in Claude Code |
