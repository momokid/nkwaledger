# Session hygiene

Long chats get summarised and early details can fade. Nothing important should live only in the chat.

- At every commit, update the task file in `docs/tasks/` and `docs/todo.md`.
- At the end of each task, say in one line whether a new session would be safer. Say yes when the chat has covered several topics, the tool outputs have been long, or a settled decision has been forgotten or asked again.
- A clean stopping point is right after a commit and a todo update. Do not suggest switching in the middle of a task.
- Also suggest a new session when the topic changes to a different area.
- When switching, do the ending steps in [../handoff/how-it-works.md](../handoff/how-it-works.md): rewrite `docs/handoff/current.md`, commit it, and tell the owner to open a new chat and say "continue". The owner should not need to copy or paste anything.
