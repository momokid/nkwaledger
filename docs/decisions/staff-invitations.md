# Invited staff set their own password

The admin never chooses a staff password. The invitation code lasts 1 hour, is sent once at creation, and is reused by `/activate`. Activated accounts can be disabled but never deleted. Unactivated invitations can be cancelled.

Open: the password rule is `min:6` everywhere, matching registration. Staff deserve a stronger rule, to be revisited.

Source: the archived phase-2 handoff.
