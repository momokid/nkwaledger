# Overview

NkwaLedger is an agricultural fintech platform for Ghanaian smallholder farmers. It turns farm activity into bankable financial records.

- Users: farmers, agents, admins, vets, advisers, suppliers.
- Channels: web (primary), USSD, mobile app later (Phase 9, offline-first, not started).
- The farmer sees a simple single-entry experience. Underneath, every record is double-entry (see domain/accounting.md).
- Farmers are low-literacy users. Screens and messages must be simple.
- Target scale: 100k+ farmers.
