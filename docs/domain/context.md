# Domain folder

How each part of the product works. One feature per file. A topic with several features gets its own folder with a context.md (see ussd/ and health-ai-review/).

| File | Read it when |
|---|---|
| accounting.md | Touching transactions, the ledger, money, periods or posting |
| stock-and-movements.md | Touching farm units, stock batches, losses, sales or the My Farm timeline |
| identity-and-permissions.md | Touching uuids, routes, roles, permissions or phone numbers |
| loans.md | Touching loans, repayments, lenders or agent entries |
| ussd/ | Touching the USSD menus, PINs or the Arkesel callback |
| health-ai-review/ | Touching disease reports, the AI draft or the officer screen |

Related: the marketplace has its own spec in docs/specs/marketplace-mvp-spec.md.
